مشروع Android لتطبيق مختبر الجمان الجانبي
=========================================

هذا مجلد مشروع Android Studio (وليس APK جاهزاً).

المتطلبات:
- Android Studio حديث.
- Android SDK Platform 35.
- اتصال إنترنت أول مرة لتنزيل Gradle وAndroid Gradle Plugin.

طريقة إنشاء APK:
1. فك ضغط Al-Juman-Android-Studio-Project.zip.
2. افتح Android Studio واختر Open.
3. اختر مجلد AlJumanAndroid.
4. انتظر Gradle Sync وتنزيل المتطلبات.
5. من القائمة Build اختر Build Bundle(s) / APK(s) ثم Build APK(s).
6. ستجد APK التجريبي عادةً في:
   app/build/outputs/apk/debug/app-debug.apk

ملاحظات مهمة:
- التطبيق يضم نسخة HTML الحالية داخل WebView ويعمل محلياً.
- الطباعة مربوطة بخدمة الطباعة في Android.
- بيانات السجلات تستخدم تخزين المتصفح المحلي داخل التطبيق؛ لا تحذف بيانات التطبيق أو تزيل تثبيته قبل تصدير/حفظ نسخة احتياطية.
- هذه حزمة مصدر قابلة للبناء وليست ملف APK موقّعاً. بيئة الإنشاء الحالية لا تحتوي Android SDK أو Gradle، لذلك لم أتمكن من تجميع APK فعلياً هنا.
- قبل الاستخدام السريري الفعلي، يجب التحقق من القوالب والوحدات والمجالات المرجعية لكل فحص وفق أجهزة المختبر وإجراءاته المعتمدة.

طريقة الحصول على APK عبر GitHub Actions (دون تثبيت Android Studio على الكمبيوتر):
1) أنشئ مستودع GitHub جديداً وارفع جميع ملفات هذا المشروع إليه (بما فيها مجلد .github).
2) افتح تبويب Actions في المستودع.
3) شغّل workflow باسم Build Al-Juman Lab APK أو انتظر اكتمال البناء بعد الرفع إلى main.
4) افتح نتيجة التشغيل الناجحة، ثم نزّل Artifact باسم Al-Juman-Lab-debug-apk.
5) فك ضغط Artifact وستجد app-debug.apk. انقله إلى هاتف Android وثبّته بعد السماح بالتثبيت من هذا المصدر.
ملاحظة: هذا APK تجريبي debug غير مخصص للنشر العام أو متجر Google Play. يلزم اختبار الطباعة والتخزين على الهاتف قبل الاستخدام الفعلي.
